# Compilador MicroPascal - Parte 1

Projeto prático da disciplina de Construção de Compiladores da Universidade Católica de Pernambuco (Unicap). Esta primeira entrega abrange a implementação do Analisador Léxico e do Analisador Sintático (Descendente Recursivo) para a linguagem simplificada MicroPascal.

## Estrutura do Repositório
* `/src`: Implementação principal em C (`Lexer.c`, `Parser.c`, `main.c`).
* `/include`: Ficheiros de cabeçalho (`.h`) contendo as definições de tokens e assinaturas.
